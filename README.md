# Colonos de Catán
El proyecto busca desarrollar una versión simplificada y funcional del juego, 
permitiendo que varios jugadores se conecten en línea para crear o unirse a 
partidas y jugar por turnos.

## Proyecto
Busca explorar la metodología Scrum, con un equipo de desarrolladores
organizado en Sprints y un Backlog gestionado mediante Github Projects.


*Sprint 1 - Online Connectivity*
Validar la comunicación en línea entre jugadores mediante un prototipo
funcional que permita conectarse a una misma sala, visualizar a los
usuarios conectados e intercambiar mensajes.

## Curent Sprint
*Sprint 2 - Creating the logic board in the backend*
Creación de hexágonos, vertices, aristas y puertos con sus respectivos 
atributos para identificarlos correctamente en el tablero. El número y 
el terreno que le corresponde a cada hexágono en el tablero es aleatorio.
